# Linux support Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Run FCU_CLOCK on Linux while preserving Windows behavior.
**Architecture:** Shared controller/HID; runtime-selected OS actions, Linux virtual input and PulseAudio-compatible audio.
**Tech Stack:** Python 3.11+, evdev, psutil, hidapi, pactl, kdotool/xdotool.
**Spec:** docs/superpowers/specs/2026-11-07-linux-design.md

## Global Constraints
- Leave WindowsActions, WindowsBackend and WindowsAppVolume unchanged.
- Work in user-selected /home/superuser/Programming/FCU_CLOCK, feature/linux.
- Keep unsupported desktops usable with explicit fallbacks.

## Review Focus
- No active window, stale process, unrelated audio: never select unrelated application streams.
- Missing executables, permissions, disconnected audio: bounded commands and actionable errors.
- HID open failure/disconnect: clean close and error status.
- --once: no desktop input dependencies required.
- Virtual keyboard errors: release modifiers and close owned device.
